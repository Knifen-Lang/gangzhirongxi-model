# 02 — 数据过滤

> 剔除字典完全抽不到技能的低质量JD

---

## 文件说明

| 文件 | 功能 |
|------|------|
| `filter_no_skill_jds.py` | 扫描已标注CSV，剔除无技术技能的JD |

## 运行

```bash
python filter_no_skill_jds.py
```

## 剔除规则

| 判定条件 | 说明 |
|---------|------|
| JD < 60字 | 信息不足以提取技能 |
| 非技术岗位 | 岗位名含：销售、客服、讲师、培训、运营、推广、营销 |
| 纯职责描述 | 有岗位名但JD全是"负责XX"无具体技术名词 |
| 产品岗无技能 | 产品经理/专员但JD纯职责描述 |

## 效果

| 数据集 | 原始 | 保留 | 剔除 |
|--------|------|------|------|
| annotated | 17,502 | 14,054 | 3,448 (19.7%) |
| jd_v2 | 31,708 | 22,884 | 8,824 (27.8%) |
| **合计** | **49,210** | **36,938** | **12,272 (24.9%)** |

## 剔除原因分布

| 原因 | 数量 |
|------|------|
| JD过短(<60字) | 6,053 |
| 纯职责描述/口语化 | 2,893 |
| 非技术岗位 | 2,581 |
| 实习/初级岗要求模糊 | 495 |
| JD偏短(<100字)且无技能 | 134 |
| 产品岗纯职责 | 105 |

## 输出

`【已标注】filtered/` — 结构同原始目录，每条JD保留原始列+7标注列。
