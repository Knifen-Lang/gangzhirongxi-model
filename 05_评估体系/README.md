# 05 — 评估体系

---

## 文件说明

| 文件 | 功能 |
|------|------|
| `evaluate_v2.py` | 7项指标全量评估（独立测试集77/10 holdout） |
| `improve_final.py` | 通胀检测改进评估+过时技能扩展+NER对比 |

## 运行

```bash
# 全量评估
python evaluate_v2.py --output eval_report.json

# 改进评估
python improve_final.py
```

## Ground Truth

- 17,502条标注JD
- 87个岗位类别
- 每JD含7列人工标注字段
- 77/10 holdout独立测试

## 通胀检测改进历程

| 版本 | 方法 | F1 |
|------|------|-----|
| 原始 | density>14 or skills>10（一刀切） | 37.0% |
| v3 | AI技能计数 + 岗位层级感知阈值 + 同义词组 + 抄袭簇 | **86.6%** |

改进关键：对标标注规范v2的同义词组检测+岗位层级(初/中/高级不同阈值)。
