**人工智能算法挑战赛 — 表格语义关系提取**
- 任务：给定 Wikidata 实体对 `(Subject, Object)`，从 563 个候选关系中预测正确关系
- 核心难点：极端长尾（131类≤5条）、细粒度混淆（author vs director）、开集实体
- 最终成绩：V3 Score 0.80+

### 4.2 三种分类器

#### JobClassifier（主分类器）
```python
class JobClassifier(nn.Module):
    """
    Encoder + Linear分类头
    分类头权重可选 岗位描述原型矩阵 初始化
    → 原型矩阵提供语义先验，冷门岗位即使0样本也能"语义检索"
    """
    def forward(input_ids, attention_mask):
        h = encoder(input_ids, attention_mask)[CLS]  # (B, 1024)
        logits = classifier(h)                        # (B, N_jobs)
        return logits, h, hidden_states
```

#### PrototypeClassifier（原型匹配辅助）
```python
class PrototypeClassifier(nn.Module):
    """
    [CLS]嵌入 与 岗位描述原型矩阵 的余弦相似度
    → 对冷门岗位提供非参数语义先验
    P(job) ∝ cos_sim(h, proto_j) / temperature
    """
    def forward(cls_embedding):
        sim = cos_sim(norm(h), norm(prototypes)) / temperature
        return sim  # (B, N_jobs)
```

#### HierarchicalJobClassifier（层级分类）
```python
class HierarchicalJobClassifier(nn.Module):
    """
    岗位族(8类) → 具体岗位(~80类) 两级分类
    粗粒度预测对细粒度施加结构性约束
    ├─ family_head: Linear(1024, 8)
    └─ job_head: Linear(1024, 80)
    job_logits += log(family_probs @ family_to_job_mask)
    → 不属于某族的岗位被自动抑制
    """
```

### 4.3 Two-Stage 训练协议

```
Stage 1: 表示学习 (15 epochs)
┌─────────────────────────────────────────────────┐
│ 目标: 学习区分性文本表示                           │
│                                                 │
│ 主损失:                                         │
│   Focal Loss (γ=2.0)        权重 1.0            │
│   + 非对称Label Smoothing   ls [0.02, 0.12]     │
│                                                 │
│ 辅助损失:                                       │
│   SupCon (同类聚集)         权重 0.2             │

│   DescAlign (描述对齐)       权重 0.1             │
│                                                 │
│ 正则化:                                         │
│   R-Drop (双向KL)           权重 0.1             │
│                                                 │
│ 采样: IB+Uniform 50/50 混合                     │

└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ 目标: 在保护表示的前提下校准分类器偏置              │
│                                                 │
│ 损失: CWBS + 自适应tau [0.3, 1.5]                │
│ 微分学习率:                                      │

└─────────────────────────────────────────────────┘
```

### 4.4 数据采样

```
Class-Balanced Sampling (CBS, β=0.999):
  p_i ∝ (1-β) / (1-β^{n_i})
  → 样本越少，采样概率越高

IB (Instance-Balanced) + Uniform 混合:
  Stage1: IB 50% + Uniform 50%
  Stage2: CWBS-weighted 80% + Uniform 20%
```

### 5.2 TTA（Test-Time Augmentation）

```python
def predict_with_tta(model, text, job_descriptions, mc_samples=5):
    for fmt in ['A', 'B', 'C']:      # 3种编码格式
        for _ in range(mc_samples):   # 5次Dropout MC前向
            model.train()             # 启用dropout
            logits = model(format_input(text, job, fmt))
            all_logits.append(logits)
    avg = mean(all_logits)
    return softmax(avg / temperature)
```

### 5.3 Bayesian kNN 非参数推理

```python
class BayesianKNNClassifier:
    """
    P(job | x) ∝ Σ_{i∈N_k(x)} exp(-d(x,xi)²/σ²) × I(yi==job)
    
    对冷门岗位(≤5条)特别有效:
    - 不依赖softmax分类器参数
    - 直接利用训练集嵌入做非参数投票
    - σ = median(k-th distance) → 自适应带宽
    
    融合: P_final = α·P_knn + (1-α)·P_ensemble
          α默认0.15，冷门岗位可提高
    """
```

### 5.4 异构集成 + 熵感知动态权重

```python
# 4个异构模型 → 4个概率矩阵
ensemble:
  M1: deberta-v3-large + focal+supcon + tau=0.5
  M2: deberta-v3-large + ce+ls        + tau=1.0
  M3: deberta-v3-base  + focal+supcon + tau=0.5
  M4: bge-large-zh     + cwbs         + tau=1.0

# Layer 1: 基于CV分数的固定权重
base_weights = CV_scores / sum(CV_scores)

# Layer 2: 逐样本熵感知动态权重
confidence_i = 1 / (entropy(P_i) + 0.1)
dynamic_weight_i = base_weight_i × confidence_i^2

# 低熵(高置信)模型权重放大，高熵(低置信)模型权重缩小
# → 防止低质量模型拖累集成
```

### 5.5 五折交叉验证

```
Data → Fold_0 Fold_1 Fold_2 Fold_3 Fold_4
        ├─ Train Train  Train  Train  → model_0
        ├─ Train Train  Train  Train  → model_1
        ├─ Train Train  Train  Train  → model_2
        ├─ Train Train  Train  Train  → model_3
        └─ Train Train  Train  Train  → model_4

推理: 5个fold的预测概率取均值
```

### 7.3 四问题质量校准框架

**入口**: `fix_four_issues.py` + `fix_inflation_hallucination.py`

四个独立可插拔的校准模块：

#### 时滞校准
```
jd_readiness = burst × max(0.1, 1.0 - lag / 18.0)
predicted_peak_month = lag
```
- 时滞 > 12 月 → burst × 0.3
- 时滞 = 0 → burst 不变

#### 通胀校准（v2：薪资分层法）
```
薪资溢价 = P(高薪 JD | 关键词) / P(高薪 JD | 全部)
```
- 溢价 ≥ 1.2 → 真实需求，不惩罚
- 溢价 0.8-1.2 → 正常，轻度惩罚（×0.85）
- 溢价 < 0.8 → buzzword 嫌疑（×0.7）
- 溢价 < 0.5 → 严重通胀（×0.5）

**v1 vs v2 改进：** v1 使用 JD 级通胀标签的加权聚合，将"JD 整体通胀"错误归因到个体关键词。v2 改用薪资分层——真实需求词在高薪 JD 中出现频率显著更高，与通胀标签无关。

#### 噪声校准
```
Fisher 精确检验 (α=0.05) + Cohen's h 效应量 (≥0.2)
```
- 有 JD 验证（jd_count > 20）→ 不受噪声惩罚
- 无 JD + 统计不显著 → burst × 0.5
- 少量 JD + 统计不显著 → burst × 0.7

**当前局限：** 13 个月窗口不足以为大多数关键词提供显著统计结果。随着数据积累（目标 24+ 月），Fisher 检验效力将显著提升。

#### 幻觉校准
对接现有 `HallucinationGuard`（4 层白名单）+ `TECH_KNOWLEDGE_BASE`（60+ 已验证技能）：

```
HallucinationGuard.validate_skill(skill, confidence=0.6):
  - 白名单命中 → verified (confidence=1.0)
  - 软技能/过时/描述性 → rejected
  - 不在白名单 → needs_review → RAG 三源验证
```

- 时滞窗口词（jd_count=0）→ 标记为 `no_data`，非幻觉问题
- 已验证技能 ≥ 70% → 低风险
- 被拒绝技能 ≥ 50% → 高风险
- 当前结果：**0 高风险，0 中风险** — 现有管线覆盖充分

## 8. 子系统F：图谱校准器

### 8.1 概述

**入口**: `graph_calibrator.py`

子系统F合并子系统A+D+E的检测结果，通过四个校准器输出干净的岗位能力图谱。核心创新是**检测→矫正闭环**——不是检测完写报告，而是把检测结果转化为矫正动作反馈到图谱构建中。

### 8.2 校准架构

```
检测结果（子系统A/D/E）
        │
        ├─ 通胀检测 → InflationCalibrator
        │     └─ 抄袭簇降权: 每条JD权重 = 1/簇大小
        │
        ├─ 时滞检测 → TimeLagCalibrator
        │     └─ 预测性激活: predicted_jd_date = tech_first_seen + 11mo
        │
        ├─ 噪声检测 → NoiseCalibrator
        │     └─ Fisher检验: 只保留 p<0.05 AND h>=0.2 的信号
        │
        └─ 幻觉检测 → HallucinationCalibrator
              └─ 4层白名单: verified/rejected/outdated/candidate
                      │
                      ▼
              calibrated_graph.json
              ┌─────────────────────┐
              │ nodes: 50           │
              │ edges: 200          │
              │ predicted_nodes: N  │
              │ stats: stable/growing/emerging │
              └─────────────────────┘
```

### 8.3 通胀校准 (InflationCalibrator)

**原理**: 同岗位JD相似度>0.8视为抄袭簇，簇内每条JD的技能计数乘以1/簇大小。

```
Before: 5条抄袭JD都写"大模型" → count=5
After:  5条抄袭JD → effective_count = 5×(1/5) = 1
```

**效果**: 4,013条JD中发现44个抄袭簇，183条JD被降权。

### 8.4 时滞校准 (TimeLagCalibrator)

**原理**: 中位数时滞11个月。对每个技术信号计算`预测JD出现日期 = 首次出现日期 + 11个月`。

```
状态机: predicted → emerging → converted
        predicted(预计N天后出现) → overdue(到期未出现,重新评估)
```

### 8.5 噪声校准 (NoiseCalibrator)

**原理**: 对比前后两个时间窗口的技能频次，Fisher精确检验+Cohen's h判定显著性。

- 302个技能中95%被过滤为噪声
- 仅14个通过(p<0.05, h≥0.2)
- 效应量分级: h≥0.5=高置信度, 0.2-0.5=中置信度

### 8.6 幻觉校准 (HallucinationCalibrator)

**原理**: HallucinationGuard四层白名单，每个技能返回verified/rejected/outdated/candidate。

- 字典中260+技能 → status='verified' (保留)
- 软技能/描述短语 → status='rejected' (移除)
- 过时技能39项 → status='outdated' (标记历史层)
- 字典外技能 → RAG三源验证

**效果**: 字典法提取88,312次，零软技能混入。只有LLM自由生成时才需RAG介入。

### 8.7 数据过滤 (filter_no_skill_jds.py)

标注管线的前置步骤，剔除字典完全抽不到技能的低质量JD。

| 数据集 | 原始 | 保留 | 剔除 |
|--------|------|------|------|
| annotated(旧) | 17,502 | 14,054 | 3,448 (19.7%) |
| jd_v2(新) | 31,708 | 22,884 | 8,824 (27.8%) |

剔除主因: JD过短6,053 + 纯职责描述2,893 + 非技术岗2,581。

输出: `【已标注】filtered/`，jd_v2是全集（智联84+猎聘80文件）。

## 9. 损失函数体系（原8）

### 8.1 损失总览

| 损失函数 | 类型 | 权重(S1) | 作用 | 来源 |
|---------|------|---------|------|------|
| **Focal Loss** | 主损失 | 1.0 | 聚焦难样本，降低易分类样本贡献 | 源项目 |
| **CWBS Loss** | 主损失(S2) | 1.0 | 频率偏置校正，公平对待冷门岗 | 源项目 |
| **SupCon Loss** | 辅助 | 0.2 | 同类嵌入聚集，异类远离 | NeurIPS 2020 |
| **SpanCL Loss** | 辅助 | 0.1 | 技能词/公司名 span 级对比 | TKRE IJCAI 2025 |
| **TripletMargin** | 辅助 | 0.05 | 混淆岗位簇在嵌入空间显式分离 | 源项目 |
| **LargeMarginLoss** | 辅助 | 0.05 | 混淆岗位簇在 logit 空间余弦间隔分离 | **新增迁移** |
| **DescAlign** | 辅助 | 0.1 | [CLS]嵌入与岗位原型对齐 | 源项目 |
| **R-Drop** | 正则化 | 0.1 | 双向KL散度，提升长尾泛化 | 源项目 |

> **TripletMargin vs LargeMarginLoss：** TripletMargin 在嵌入空间施加间隔，LargeMarginLoss 在 logit 空间施加余弦间隔。两者互补——前者学更好的表示，后者学更好的决策边界。LargeMarginLoss 含自适应变体，冷门类 margin 更大。

### 8.2 Focal Loss

```python
FL(p_t) = -α_t × (1-p_t)^γ × log(p_t)

α_t = (max_count - n_class + min_count×0.1) / (max_count + min_count×0.1)
# 样本越少 α 越大 → 放大尾部梯度

γ = 2.0  # 降低易分类样本的损失贡献
# p_t=0.9 → (1-0.9)²=0.01 → 几乎为零
# p_t=0.1 → (1-0.1)²=0.81 → 保留大部分

非对称Label Smoothing:
  ls_class = 0.12 - (0.12-0.02) × (n-n_min)/(n_max-n_min)
  # 头类(样本多)→0.02: 几乎不模糊，保持精度
  # 尾类(样本少)→0.12: 强平滑，防止对少量样本过拟合
```

### 8.3 CWBS Loss

```python
CWBS = -w_y × log[exp(f_y + τ_y·log π_y) / Σ_j exp(f_j + τ_j·log π_j)]

w_y: 比赛权重（样本越少权重越大）
log π_y: 类别先验频率对数 → Balanced Softmax 频率偏置校正
τ_y: 自适应偏置强度
  # 尾类(样本少) → τ大(1.5): 强校正 → 输出更"公平"
  # 头类(样本多) → τ小(0.3): 弱校正 → 保留模型判断

# 类频率偏置: 将模型输出"拉回"真实频率分布
# 尾类log π→大负数 → 加偏置后→更公平
```

### 8.4 SupCon Loss

```python
L_supcon = -1/|P(i)| Σ_{p∈P(i)} log[exp(z_i·z_p/τ) / Σ_{a≠i} exp(z_i·z_a/τ)]

P(i): 与样本i同类的其他样本（正样本对）
τ = 0.07: 温度参数

# 效果: 同岗位的嵌入被"拉近"，不同岗位的嵌入被"推远"
# In-batch negatives: 利用batch内其他类样本作为负例
```

### 8.5 SpanCL Loss

```python
# 用[SEP]分割输入: 岗位描述 [SEP] 简历文本 [SEP]
# 分别对岗位描述span和简历span做对比学习

job_embed  = mean(h[1:sep1])    # 岗位描述部分
resume_embed = mean(h[sep1+1:sep2])  # 简历部分

# 正样本: 同岗位下不同样本的 job_embed / resume_embed
# 负样本: 不同岗位的 span 嵌入

L_spancl = (L_contrast(job_embeds, labels) + L_contrast(resume_embeds, labels)) / 2
```

## 9. 模型架构详解

### 9.1 Encoder选型

| 模型 | 维度 | 参数量 | 层数 | 注意力头 | 选型理由 |

| **DeBERTa-v3-large** | 1024 | 304M | 24 | 16 | RTD+GDES最强表示 |

**DeBERTa-v3 优势：**

- 在SuperGLUE等基准上超越RoBERTa/XLNet

### 9.2 输入格式设计


## 11. 数据流全链路

### 11.1 标注链路（单条JD）

```
原始CSV行 (job_name, skill_requirements, ...)
  │
  ├─ is_it_industry()           ← 清洗
  │   └─ 非IT → 跳过
  │
  ├─ extract_skills_from_text() ← 词典抽取
  │   └─ 未命中 → LLMSkillExtractor.extract() ← 五级管线
  │       └─ 未命中 → 标记"未识别"
  │
  ├─ annotate_row()             ← 六项标注
  │   ├─ classify + mastery     ← 分类+掌握级别
  │   ├─ required vs bonus      ← 必备/加分流
  │   ├─ detect_inflation()     ← 通胀判定
  │   ├─ detect_outdated()      ← 过时检测
  │   ├─ is_new_job_v2()        ← 新岗位判定
  │   └─ check_ability_update() ← 能力更新
  │
  └─ 输出CSV行 (原始列 + 7标註列)
```

### 11.2 训练链路（全量数据）

```
已标注数据 (31,708条) + LLM合成数据
  │
  ├─ 数据预处理
  │   ├─ 岗位标签编码 (LabelEncoder)
  │   ├─ 岗位描述模板化
  │   └─ 5-Fold CV划分
  │
  ├─ Stage 1: 表示学习 (15 epochs)
  │   └─ Focal + SupCon + SpanCL + Triplet + DescAlign + R-Drop
  │
  ├─ Stage 2: CWBS校准 (8 epochs)
  │   └─ CWBS + 自适应tau + 微分学习率
  │
  └─ 输出
      ├─ 5个fold模型权重
      ├─ 训练集嵌入（供kNN使用）
      └─ 岗位原型矩阵
```

### 11.3 推理链路（单条查询）

```
输入简历文本
  │
  ├─ 多格式编码 (A/B/C)
  ├─ 4个异构模型 → MC Dropout ×5 → 12+4=16组概率
  │   └─ 熵感知动态权重集成 → P_ensemble
  │
  ├─ Bayesian kNN → P_knn
  │
  ├─ 自适应λ融合 → P_final
  │
  ├─ 温度缩放 (T=1.5) → P_calibrated
  │
  └─ Top-K 岗位 + 置信度
```
