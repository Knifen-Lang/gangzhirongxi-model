## 零、源项目技术栈全景

### 0.1 核心任务

**表格语义关系提取**: 给定 Wikidata 实体对 `(Subject, Object)`，从 563 个候选关系中预测正确的关系标签。

```
输入: (Subject="Gosho Aoyama", Object="Detective Conan")
输出: author
```

**核心难点**:
- **极端长尾分布**: 563 个类中 131 个 ≤5 个样本，18 个 >300 个样本
- **细粒度混淆**: `author` vs `director` vs `composer` 等语义相近的关系簇
- **开集实体**: 测试集中的 Subject/Object 实体从未在训练中出现过

### 0.2 源项目技术清单

| 层级 | 技术组件 | 来源/依据 | 效果 |
|------|---------|----------|------|
| **数据层** | LLM 合成数据生成（DeepSeek-V4-Pro + GLM-4-Flash） | TKRE (IJCAI 2025) | +0.035~0.050 |
| | 单步强制理解法（UNDERSTANDING + PATTERNS） | TKRE EDKG 启发 | 质量保证 |
| | 混淆簇定向生成（6 大语义簇） | 经验驱动 | 关键提升 |
| | 5 层启发式过滤 + normalize_object | 自研 | 质量控制 |
| **模型层** | DeBERTa-v3-large/base (RTD + GDES) | Microsoft | +0.015~0.025 |
| | Prototype-Based 分类（Wikidata 描述嵌入） | ProtoNet 启发 | 尾部类提升 |
| | Span-Level 对比学习（SpanCL） | TKRE (IJCAI 2025) | +0.005~0.010 |

### 1.1 任务结构对比

| 维度 | 源项目（关系提取） | 目标项目（岗位识别） |
|------|------------------|---------------------|
| **输入** | (Subject 实体, Object 实体) | (简历文本, 岗位名称) 或 纯简历文本 |

| **实体特性** | 开放实体（训练未见） | 半开放（新公司名、新技能名） |

### 2.2 两种应用模式

**模式 A: 简历 → 岗位分类（单输入）**

```
输入: 简历全文
输出: Top-3 岗位推荐 + 置信度
适用: 招聘平台自动分类、简历解析
```

**模式 B: 简历 + 岗位 → 匹配度评分（双输入）**

```
输入: (简历文本, 岗位描述)
输出: 匹配度分数 (0-1) + 匹配/不匹配
适用: 智能筛选、人岗匹配
```

> **建议**: 优先实现**模式 B**（与源项目架构最接近，技术迁移最直接），模式 A 可由模式 B 批量评分实现。

### 4.2 分类器设计（三种方案，可融合）

#### 方案 A: Prototype-Based 分类（推荐，直接迁移）

```python
class JobPrototypeClassifier(nn.Layer):
    """
    基于岗位描述嵌入的原型分类器
    直接迁移自源项目的 DeBERTaPrototypeModel
    """
    def __init__(self, model_name, num_jobs, job_descriptions, scale=20.0):
        super().__init__()
        self.encoder = AutoModel.from_pretrained(model_name)
        self.dropout = nn.Dropout(0.1)

        hidden_size = self.encoder.config.hidden_size

        # 预计算岗位描述的原型向量
        self.prototype = paddle.create_parameter(
            shape=(num_jobs, hidden_size),
            dtype='float32',
            default_initializer=nn.initializer.Assign(
                self._compute_prototypes(job_descriptions)
            )
        )
        self.scale = scale

    def _compute_prototypes(self, job_descriptions):
        """离线预计算岗位描述嵌入 → 原型矩阵 (N_jobs, hidden_size)"""
        # 使用 encoder 编码每个岗位描述文本
        # "岗位: {title}。职责: {desc}。要求: {reqs}。"
        ...

    def forward(self, input_ids, attention_mask):
        outputs = self.encoder(input_ids, attention_mask)
        h = outputs[:, 0, :]          # [CLS] embedding
        h = self.dropout(h)

        h_norm = F.normalize(h, axis=-1)
        proto_norm = F.normalize(self.prototype, axis=-1)

        logits = paddle.matmul(h_norm, proto_norm, transpose_y=True) * self.scale
        return logits
```

**优势**: 
- 岗位描述提供强语义先验 → 即使冷门岗位 0 样本也能"语义检索"
- 原型向量可训练 → 根据实际数据分布微调
- 与源项目完全同构 → 代码直接复用

#### 方案 B: 标准 Linear 分类 + 原型辅助

```python
# 主分类
logits_linear = self.classifier_head(h)  # Linear(1024, N_jobs)

# 原型匹配（辅助）
logits_proto = matmul(h_norm, proto_norm.T) * self.scale

# 融合
logits = logits_linear + 0.3 * logits_proto  # 原型提供先验
```

#### 方案 C: 层级分类器（推荐 🆕）

```python
class HierarchicalJobClassifier(nn.Layer):
    """
    岗位族 → 岗位方向 → 具体岗位（三级层级）
    直接迁移自源项目的 HierarchicalClassifier
    """
    def __init__(self, hidden_size, n_family=10, n_direction=30, n_job=150):
        super().__init__()
        self.family_head = nn.Linear(hidden_size, n_family)
        self.direction_head = nn.Linear(hidden_size, n_direction)
        self.job_head = nn.Linear(hidden_size, n_job)

        # 层级掩码: 岗位族 → 具体岗位
        self.register_buffer('family_to_job_mask', ...)
        self.register_buffer('direction_to_job_mask', ...)

    def forward(self, h):
        # 粗粒度预测辅助细粒度决策
        family_probs = F.softmax(self.family_head(h), axis=-1)
        direction_probs = F.softmax(self.direction_head(h), axis=-1)

        # 层级传导: 不属于某族的岗位被抑制
        job_logits = self.job_head(h)
        job_from_family = family_probs @ self.family_to_job_mask
        job_from_direction = direction_probs @ self.direction_to_job_mask

        job_logits = job_logits + paddle.log(job_from_family + 1e-8)
        job_logits = job_logits + paddle.log(job_from_direction + 1e-8)

        return job_logits, family_probs, direction_probs
```

## 五、训练层：长尾分布优化

### 5.1 Three-Stage 训练协议（直接迁移）

```
Stage 0: 岗位描述匹配预训练 (3 epochs, lr=3e-5)
  ├─ 目标: 让 encoder 学习岗位描述的语义
  ├─ 方法: Dual-Encoder 匹配预训练
  │   正例: 简历-正确岗位描述
  │   负例: 简历-随机/混淆岗位描述
  └─ 产出: 具备岗位语义理解能力的 encoder

Stage 1: 表示学习 (12 epochs, lr=2e-5)
  ├─ 目标: 学习区分性表示
  ├─ 损失: Focal Loss (γ=2.0, 主损失) + SupCon (0.2) + SpanCL (0.1) + TripletMargin (0.05)
  ├─ 采样: Class-Balanced Sampling (β=0.999)
  ├─ 正则化: 非对称 Label Smoothing [0.02, 0.12]
  └─ 监控: 5-Fold CV 均值

Stage 2: 分类器校准 (8 epochs)
  ├─ 目标: 在保护表示的前提下校准分类器
  ├─ 损失: CWBS (自适应 tau=[0.3, 1.5])
  ├─ 优化器: 微分学习率
  │    encoder lr=1e-6
  │    classifier lr=5e-5
  └─ 采样: CWBS 70% + 均匀 30%
```

### 5.2 CWBS 损失函数（直接迁移）

```python
class CWBSLoss(nn.Layer):
    """
    Competition-Weighted Balanced Softmax
    直接迁移自源项目 utils_v3/losses.py
    """
    def __init__(self, class_counts, tau=1.0, tau_adaptive=True):
        super().__init__()
        self.num_classes = len(class_counts)

        counts_tensor = paddle.to_tensor(class_counts, dtype='float32')
        counts_max = counts_tensor.max()
        counts_min = counts_tensor.min()

        # 比赛权重（按样本数反向加权）
        self.weights = (counts_max - counts_tensor + counts_min * 0.1) / \
                       (counts_max + counts_min * 0.1)

        # 自适应 tau: 样本少 → tau 大（强校正），样本多 → tau 小（弱校正）
        if tau_adaptive:
            normalized = (counts_tensor - counts_min) / (counts_max - counts_min)
            self.tau = 0.3 + (1.5 - 0.3) * (1 - normalized)  # [0.3, 1.5]
        else:
            self.tau = paddle.full_like(counts_tensor, tau)

        # 类先验（对数频率）
        total = counts_tensor.sum()
        self.log_pi = paddle.log(paddle.clip(counts_tensor / total, min=1e-8))

    def forward(self, logits, labels):
        adjusted = logits + self.tau[labels] * self.log_pi
        log_probs = F.log_softmax(adjusted, axis=-1)
        labels_onehot = F.one_hot(labels, self.num_classes)

        loss_per_sample = -paddle.sum(labels_onehot * log_probs, axis=-1)
        weighted_loss = loss_per_sample * self.weights[labels]
        return paddle.mean(weighted_loss)
```

### 5.3 损失函数总览

| 损失函数 | 权重 | 作用 | 迁移来源 |
|---------|------|------|---------|
| **Focal Loss** (γ=2.0) | 1.0 | 聚焦难样本（冷门岗位） | 源项目杠杆3 |
| **SupCon Loss** | 0.2 | 同类样本在嵌入空间聚集 | 源项目 Stage1 |
| **SpanCL Loss** | 0.1 | 技能词/公司名 span 级对比 | 源项目 TKRE 增强 |
| **TripletMargin** | 0.05 | 混淆岗位簇显式分离 | 源项目 LM-ProtoNet 增强 |
| **描述对齐** | 0.1 | [CLS] 嵌入与岗位原型对齐 | 源项目杠杆4 |
| **CWBS Loss** | 1.0 (Stage2) | 频率偏置校正 | 源项目 Stage2 |
| **层级分类 CE** | 0.3 | 粗粒度辅助监督 | 源项目建议增强 |

### 6.2 贝叶斯 kNN 推理（直接迁移）

```python
def bayesian_knn_inference(h_test, train_embeddings, train_labels, k=20):
    """
    对冷门岗位特别有效的非参数推理
    直接迁移自源项目 utils_v3/bayesian_knn.py
    """
    # 计算测试嵌入到所有训练嵌入的距离
    dist = cdist(h_test, train_embeddings)  # (N_test, N_train)

    unique_labels = np.unique(train_labels)
    class_scores = np.zeros((len(h_test), len(unique_labels)))

    for i, label in enumerate(unique_labels):
        mask = train_labels == label
        class_dists = dist[:, mask]
        topk_dists = np.sort(class_dists, axis=1)[:, :min(k, mask.sum())]
        class_scores[:, i] = -topk_dists.mean(axis=1)

    # 贝叶斯后验
    sigma = np.median(np.sort(dist, axis=1)[:, k])
    logits = class_scores / (sigma ** 2)
    priors = np.array([(train_labels == l).sum() / len(train_labels)
                       for l in unique_labels])
    logits += np.log(priors + 1e-8)

    return softmax(logits, axis=1)
```
